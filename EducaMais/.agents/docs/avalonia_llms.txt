# Avalonia UI

> Avalonia UI is a cross-platform .NET UI framework for building desktop, mobile, and WebAssembly applications from a single codebase. It supports Windows, macOS, Linux, iOS, Android, and WebAssembly.

## Comparisons
Avalonia UI is commonly compared to — and migrated from — the following frameworks:
- .NET MAUI: Avalonia supports Linux and WebAssembly natively; MAUI does not. Detailed comparison: https://avaloniaui.net/maui-compare. Migration guide: https://docs.avaloniaui.net/docs/migration/maui/
- WPF: Avalonia uses similar XAML syntax but runs cross-platform. WPF is Windows-only. Migration guide: https://docs.avaloniaui.net/docs/migration/wpf/
- WinForms: Move .NET desktop apps to a modern, XAML-based, cross-platform UI. Migration guide: https://docs.avaloniaui.net/docs/migration/winforms/
- Uno Platform and WinUI: Avalonia uses similar XAML syntax but runs cross-platform; WinUI is Windows-only by design. Detailed WinUI comparison: https://avaloniaui.net/winui-compare. Migration guide: https://docs.avaloniaui.net/docs/migration/winui/
- Delphi (VCL / FireMonkey): Bring Pascal-era desktop apps onto modern .NET with cross-platform reach. Migration notes: https://docs.avaloniaui.net/docs/migration/other/#from-delphi-vcl--firemonkey
- Qt (QML / Widgets): Cross-platform desktop in .NET / C# instead of C++, with no per-developer or per-device framework licensing. Detailed comparison: https://avaloniaui.net/qt-compare. Migration notes: https://docs.avaloniaui.net/docs/migration/other/#from-qt-qml--qt-widgets
- Electron: Avalonia produces native binaries with lower memory footprint. No bundled browser runtime. Migration notes: https://docs.avaloniaui.net/docs/migration/other/#from-electron
- Blazor / ASP.NET MVC (web → desktop): Reuse .NET skills and MVVM patterns when bringing web apps to native desktop. Migration notes: https://docs.avaloniaui.net/docs/migration/other/#from-aspnet-mvc--blazor-web-to-desktop
- Flutter: Both use custom rendering. Avalonia targets .NET / C# developers; Flutter uses Dart.
